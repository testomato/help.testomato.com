## Overview

Testomato Help & Docs site built with Docusaurus 3. Serves `help.testomato.com`. Runs in docs-only mode (no blog) — all documentation routes are served from `/` instead of `/docs/`.

## Commands

```bash
yarn start            # Dev server with hot reload
yarn build            # Production build to build/
yarn typecheck        # TypeScript type checking
yarn prettier         # Format JS and MD files
yarn prettier:diff    # Check formatting (dry-run)
yarn clear            # Clear Docusaurus cache (use when things are stale or broken)
yarn api              # Generate API reference docs from OpenAPI spec
yarn api.clean        # Delete generated API docs
yarn api.regenerate   # Clean + regenerate API docs
yarn api.mocks        # Generate OpenAPI components from JSON/YAML mock files in api/mocks/
```

## Architecture

- **Docusaurus 3** with `preset-classic` in docs-only mode (`routeBasePath: '/'`)
- **OpenAPI docs** generated by `docusaurus-plugin-openapi-docs` from `api/testomato.yaml` into `docs/api/`. These files are auto-generated — edit the YAML spec, not the generated markdown
- **Search** via `docusaurus-lunr-search` (client-side)
- **Formatting** uses Prettier (not Biome, unlike the other Testomato JS projects); config (`.prettierrc`): single quotes, no bracket spacing, `printWidth: 80`, `proseWrap: never`; only applies to `**/*.{js,md}` (not `.ts`/`.mdx`)
- **Repo** lives on GitHub (`testomato/help.testomato.com`), not GitLab like the other Testomato sub-projects

## Content Structure

- `docs/` — Markdown/MDX documentation pages. Files are numbered-prefixed for sidebar ordering (e.g., `01-introduction.mdx`, `02-dashboard.md`)
- `docs/api/` — Auto-generated API reference (do not edit manually; also includes `sidebar.ts` which is auto-generated and imported by `sidebars.ts`)
- `api/testomato.yaml` — OpenAPI 3.0.3 spec, the source of truth for API docs
- `api/schemas/`, `api/responses/`, `api/mocks/` — Reusable OpenAPI components referenced by `testomato.yaml`
- `sidebars.ts` — Manual sidebar config that mixes explicit doc IDs with `autogenerated` categories and the generated `ApiSidebar`
- `src/pages/index.tsx` — Simple redirect to `/introduction`; not a custom homepage
- `src/css/custom.css` — Theme customizations
- `plugins/webpack-fallbacks.js` — Adds `path-browserify` polyfill needed by the OpenAPI plugin

## Sidebar Organization

Sidebar in `sidebars.ts` uses a mix of explicit doc references and `autogenerated` directory scans. Categories: Billing & Payment (`payment/`), Monitoring (`monitoring/`), TestomatoBot (`bot/`), Checks (`checks/`), and API Reference (from generated OpenAPI sidebar).
