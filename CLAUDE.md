# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Testomato Help & Docs site built with Astro + Starlight. Serves `help.testomato.com`. Docs live at the site root (`/introduction`, `/checks/xpath`) rather than under `/docs/`.

## Commands

```bash
yarn start            # Dev server with hot reload (astro dev)
yarn build            # Production build to dist/
yarn preview          # Serve the production build locally
yarn typecheck        # astro check (NOT `yarn check` — yarn v1 shadows that name)
yarn prettier         # Format JS/MJS/MD/MDX files
yarn prettier:diff    # Check formatting (dry-run)
```

## Architecture

- **Astro 7 + Starlight 0.42**, default Starlight theme — no custom CSS, no component overrides
- **URLs** are pinned by `trailingSlash: 'never'` + `build.format: 'file'` in `astro.config.mjs`. This reproduces the paths Docusaurus emitted, so nothing already indexed or linked from `testomato.com` moves. Don't change either without a redirect plan
- **OpenAPI docs** rendered at build time by `starlight-openapi` straight from `api/testomato.yaml`. Nothing is generated into the repo — there is no `api.regenerate` step any more, and no committed API markdown
- **Redirects** live in `astro.config.mjs`. Static output means Astro emits a meta-refresh page per entry. Every URL the Docusaurus site served is either still a real page or listed there
- **Search** is Pagefind, built in to Starlight (no plugin, no config)
- **Sitemap** is generated by Starlight via `@astrojs/sitemap`; redirect pages are excluded automatically
- **Deploy** is `.github/workflows/deploy.yml` — pushes to `master` build and publish to GitHub Pages via `withastro/action`. Pages must be set to the "GitHub Actions" source (`build_type: workflow`), not a branch
- **Formatting** uses Prettier (not Biome, unlike the other Testomato JS projects); config (`.prettierrc`): single quotes, no bracket spacing, `printWidth: 80`, `proseWrap: never`
- **Repo** lives on GitHub (`testomato/help.testomato.com`). The GitLab mirror is archived and read-only

## Content Structure

- `src/content/docs/` — Markdown/MDX pages. The file path _is_ the URL; there are no numeric filename prefixes
- `src/content/docs/404.md` — custom not-found page, picked up by Starlight's own `/404` route
- `src/content.config.ts` — Starlight's `docs` and `i18n` collections. `i18n` is declared (with an empty `src/content/i18n/en.json`) purely to silence a build warning on a monolingual site
- `api/testomato.yaml` — OpenAPI 3.0.3 spec, the source of truth for the API reference
- `api/schemas/`, `api/responses/`, `api/mocks/` — reusable OpenAPI components referenced by `testomato.yaml`
- `public/` — served verbatim: `img/`, plus `CNAME` and `.nojekyll` that GitHub Pages needs

## Sidebar and ordering

The sidebar is defined explicitly in `astro.config.mjs`. Groups (Billing & Payment, Monitoring, TestomatoBot, Checks) use `items: [{ autogenerate: { directory: ... } }]`; ordering inside them comes from `sidebar.order` in each page's frontmatter, which replaced the old numeric filename prefixes. The API Reference group is injected by `openAPISidebarGroups`.

## Frontmatter

Starlight requires `title` on every page. `sidebar.label` overrides the sidebar text, `sidebar.order` sets position, `sidebar.hidden` keeps a page out of the tree, and `slug` overrides the URL — `checks/csrf-protection.md` uses it to keep serving the historic `/checks/CSRF-protection`.

Asides use Starlight's four types: `:::note`, `:::tip`, `:::caution`, `:::danger` (with an optional `[Custom title]`). Docusaurus's `:::info`, `:::warning` and `:::important` do not exist here.
